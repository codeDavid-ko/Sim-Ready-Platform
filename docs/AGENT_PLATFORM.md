# 에이전트 플랫폼 — 소개 & 워크플로우 안내

## 1. 한 줄 소개

**구독 Claude(에이전트)가 여러 엔진·도구를 구동해, 3D 형상을 "시뮬레이션에 바로 쓸 수 있는(sim-ready)" USD로 만들어 주는 웹 플랫폼**입니다.
사용자는 **카드(워크플로우)** 를 골라 파일/텍스트/이미지를 넣고 실행하면, 결과(USD·물성·재질·텍스처·관절·스크린샷)와 브라우저 3D 미리보기를 받습니다.

## 2. 어떻게 동작하나 (에이전트 관점)

- **에이전트 = 구독 Claude**: 모든 분류·추론·모델링을 Max 구독(OAuth)으로 호출합니다. **별도 API 키 과금 없음.**
- Claude가 카드별로 **외부 엔진/도구를 구동**합니다:
  - **NVIDIA content-agents** (재질/물리/텍스처) — WSL에서 멀티뷰 렌더 + VLM 추론
  - **Trinix CAD (MCP)** — 텍스트/이미지로 3D 모델 빌드
  - **로컬 Stable Diffusion** — 텍스처 이미지 생성(무료, GPU)
  - **ndotsim 로직** — 형상에서 정확 질량·물성 계산 + Claude 재질/물리 추론
- **카드 추가가 쉬움**: 폴더에 매니페스트(JSON)만 넣으면 카드가 늘어나는 구조(매니페스트 기반 레지스트리).
- **렌더링**: 결과 USD를 **Omniverse/Isaac Sim RTX**로 렌더 → 브라우저에서 **마우스로 회전(SpinViewer)** 하거나 PBR 근사 GLB로 즉시 미리보기.

## 3. 접속 / 운영

- **로그인**: 아이디/비밀번호. 최초 1회 관리자 계정을 직접 설정. 관리자는 사용자 추가·권한·비밀번호 관리.
- **외부 공개**: 관리자 패널에서 Cloudflare 임시 URL(`*.trycloudflare.com`)을 켜고/끌 수 있음(로그인 보호).
- **비용**: 재질·물리·모델링·분류는 구독 Claude로 무료. **외부 키가 필요한 건 NVIDIA 텍스처 생성(diffusion)뿐**.

## 4. 워크플로우(카드) 안내

상태: ✅ 사용 가능 · 🔒 조건부 비활성

### 🟦 NdotLight Trinix (자체 엔진)

#### 재질 추론 USD  ✅
- **무엇**: 형상을 올리고(또는 이미지/설명) 부품별로 어떤 재질인지 추론 → **vMaterials(MDL) 재질이 입혀진 USD** 생성.
- **입력**: STL/STEP/USD/메시 (+ 선택: 참조 이미지·텍스트 힌트)
- **출력**: 재질 바인딩 USD + PBR 미리보기 + Omniverse RTX 뷰어
- **용도**: 렌더링·룩 확인용 재질.

#### 물리 추론 (질량·접촉물리)  ✅
- **무엇**: 형상에서 **정확 질량·관성·무게중심**을 계산(LLM 아님)하고, 구독 Claude로 **재질(밀도)·마찰·반발**을 추론 → **UsdPhysics USD**.
- **입력**: STEP/STL/USD (+ 선택: 맥락 힌트·참조 이미지)
- **출력**: 부품별 질량·밀도·마찰·반발 표 + UsdPhysics USD(usdchecker 통과) + RTX 뷰어
- **원리**: `질량 = 밀도(추론) × 부피(형상 정확값)`. 12종 고정 물성표 기준(ndotsim 사양).

#### 텍스처 생성 (Stable Diffusion · 로컬)  ✅
- **무엇**: 텍스트 프롬프트로 **PBR 텍스처(albedo+normal+roughness)** 를 로컬 Stable Diffusion(SD-Turbo)으로 생성. **외부 키 불필요, GPU 무료.**
- **입력**: 프롬프트(영어 권장) + 해상도/스텝/시드
- **출력**: 타일 텍스처 맵(PNG) + 인터랙티브 미리보기 + USD/USDZ
- **용도**: 무료 텍스처. NVIDIA 텍스처 카드(키 필요)의 대안.

#### 3D 모델링 (Trinix CAD)  ✅ (스크린샷 모드)
- **무엇**: 이미지/텍스트(도면·설명)를 넣으면 구독 Claude가 **Trinix CAD(MCP)** 로 3D 모델을 부품 단위로 빌드 → **여러 각도 스크린샷**으로 보여줌.
- **입력**: 텍스트(치수·설명) + 참조 이미지
- **출력**: 다각도 RTX 스크린샷 + 부품 표 + **bbox 프록시 USD/STL**(부품 위치·크기·이름은 정확, 블록 근사)
- **참고**: Trinix 정밀 형상 export(`export_scene`)가 현재 서버측 고장이라, 정밀 형상 파일은 복구 후 추가. 지금은 스크린샷(정밀 시각) + bbox 프록시(구조/배치)로 제공.
- **전제**: `TRINIX_AI_TOKEN` + 브라우저에서 Trinix 에디터 열고 MCP 연결(녹색).

#### 3D 모델링 → 재질·물성 (Trinix 파이프라인)  🔒
- **무엇**: Trinix 3D(STEP) → 부품별 재질 + 질량·물성까지 한 번에.
- **상태**: Trinix 정밀 export 복구가 필요해 **비활성**(개발중). 복구 시 즉시 활성화 가능.

### 🟩 NVIDIA Content Agents

#### 재질 추론 (NVIDIA 엔진)  ✅
- **무엇**: USD를 NVIDIA content-agents로 처리 — WSL 멀티뷰 렌더 + VLM(구독 Claude)으로 **부품별 재질** 추론 → 재질 바인딩 USD.
- **입력**: USD · **출력**: 재질 USD + 미리보기 + RTX 뷰어

#### 물리 추론 (NVIDIA 엔진)  ✅
- **무엇**: VLM이 **밀도·질량·마찰·반발을 직접 추정** → UsdPhysics USD. (NdotLight가 "형상 실측+고정표"인 반면 NVIDIA는 "VLM 추정")
- **입력**: USD · **출력**: 부품별 물성 + UsdPhysics USD + RTX 뷰어

#### 텍스처 추론 (NVIDIA 엔진)  🔒
- **무엇**: NVIDIA 엔진으로 재질/텍스처 추론·생성.
- **상태**: 텍스처 *생성*은 diffusion(이미지 생성) 모델이라 **`NVIDIA_API_KEY` 필요** → 키 없으면 비활성. (무료 대안: 위 "텍스처 생성(SD)")

### ⚖️ 비교 (Comparison)

#### 엔진 비교: 재질  ✅
- 같은 USD를 **NdotLight vs NVIDIA** 재질 추론에 모두 돌려 부품별 결과를 나란히 비교. 양쪽 USD/RTX 뷰 제공.

#### 엔진 비교: 물리  ✅
- 같은 USD를 두 물리 엔진에 돌려 **부품별 밀도·질량·마찰**을 대조. "형상 실측+고정표(NdotLight)" vs "VLM 추정(NVIDIA)" 차이를 한눈에.

### 🧰 기타 (유틸리티)

#### 형상 → USD 변환 (에셋 준비)  ✅
- **무엇**: STEP/STL/OBJ/GLB/PLY 메시를 **sim-ready USD**(Z-up·meters·충돌·리지드바디)로 정규화·검증.
- **용도**: 다른 카드(재질/물리/관절)에 넣기 전 형상 전처리.

#### 관절 추가 (Articulation)  ✅
- **무엇**: STEP/USD를 올려 **3D 뷰 + 구조 트리**로 보면서, 부품을 골라 **관절(회전/직선/고정) + 축 + 한계**를 지정 → **UsdPhysics 조인트**가 들어간 USD.
- **특징**: 3D에서 부품 직접 클릭(또는 트리에서 선택), 표면 클릭으로 피벗 지정, 한계(°/m) 설정, **움직임 미리보기 애니메이션**. **원본 계층 보존**(구조 안 깨짐).
- **입력**: STEP/USD · **출력**: 관절 USD(.usd) + RTX 뷰어

## 5. 결과 보기 (공통)

- **PBR 근사 GLB**: 브라우저에서 즉시 마우스 회전(색/금속성/거칠기 근사)
- **Omniverse RTX 턴테이블(mp4)** / **인터랙티브 RTX 뷰어(드래그 회전)**: Isaac Sim RTX로 렌더한 실제 재질 룩(Omniverse GUI와 동일 렌더러)

## 6. 권장 흐름 예시

1. (STEP/STL이면) **형상 → USD 변환**으로 USD 정규화
2. **재질 추론** + **물리 추론** (또는 "엔진 비교"로 두 엔진 대조)
3. 필요시 **텍스처 생성(SD)** · **관절 추가**
4. 각 결과를 RTX 뷰어로 검수 후 USD 다운로드 → Isaac Sim 등에서 사용

## 7. 두 엔진 철학 차이 (요약)

| | NdotLight (자체) | NVIDIA content-agents |
|---|---|---|
| 접근 | 형상 실측 + 고정 reference 표 + 구독 Claude | 멀티뷰 렌더 + VLM 직접 추정 |
| 재질 어휘 | 정밀(vMaterials MDL) / 물성 12종 고정 | 일반군(metal·plastic·rubber…) |
| 질량·물성 | 형상 정확 부피 × 표 밀도(결정론) | VLM이 밀도·질량·마찰 추정(유연) |
| 강점 | 재현성·공학 정확도 | 한 번에 폭넓게, 새 형상에 유연 |
